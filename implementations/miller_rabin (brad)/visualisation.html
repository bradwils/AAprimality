Each cell is one base a. Witness: Miller-Rabin proves n composite. Liar: the base passes. For any odd composite n, at most 1/4 of bases are liars, so each random round errs with probability ≤ 1/4.

How it works

  1. Write n − 1 = 2s · d with d odd.
  2. Compute x = ad mod n.
  3. If x = 1 or x = n−1, n passes for this base.
  4. Otherwise square x up to s−1 times. If x ever becomes n−1, n passes.
  5. If x never hits n−1, a is a witness: n is definitely composite.

Why it works: for prime n, the only square roots of 1 mod n are ±1, so the chain ad, a2d, …, an−1 must either start at 1 or reach −1 right before hitting 1. A composite n has extra square roots of 1, which show up as a chain that jumps to 1 from something other than −1 (or never reaches 1 at all, which Fermat would also catch). Compare with Fermat, which only checks an−1 ≡ 1 and so is fooled by Carmichael numbers such as 561 (try the preset: Fermat has no witnesses coprime to n, Miller-Rabin has plenty).
